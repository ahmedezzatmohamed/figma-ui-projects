# 🎨 Figma UI/UX Portfolio

Welcome to my **Figma UI/UX Portfolio**! This repository contains a collection of design projects created in **Figma**, showcasing my skills in user interface design, user experience, wireframing, prototyping, and design systems.

## 📌 About

This repository serves as my personal design portfolio, featuring projects across different industries and platforms. Each design focuses on creating intuitive, visually appealing, and user-centered experiences while following modern UI/UX best practices.

## 🚀 Projects

### 🍔 Food Delivery App

A modern mobile application for ordering food online with a clean user interface, intuitive navigation, and seamless checkout experience.

### 👟 Nike Website

A responsive e-commerce website concept featuring premium product pages, engaging animations, and a modern shopping experience.

### 🎬 Netflix Landing Page

A redesigned streaming platform landing page with an emphasis on typography, content discovery, and user engagement.

### 🎧 Headphone Store

A product showcase and shopping interface designed to provide a premium browsing experience for audio products.

### 💳 Money App

A mobile banking application featuring account management, transaction history, budgeting tools, and financial insights.

### 🎵 Music App

A modern music streaming application with playlist management, album discovery, and an intuitive media player.

### 🚖 Bolt Mobile App

A ride-hailing application concept with trip booking, live tracking, and a clean user-friendly interface.
